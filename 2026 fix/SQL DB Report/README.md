# SQL DB Report

এই ফোল্ডারটি তৈরি করা হয়েছে অন্য AI প্ল্যাটফর্ম থেকে প্রাপ্ত ডাটাবেস অ্যানালাইসিস রিপোর্ট (Merit List - 'F' grade issue) আপলোড করার জন্য।

**উদ্দেশ্য:**
২০২৬ সালের প্রজেক্টে মেরিট লিস্টে সকল স্টুডেন্টের রেজাল্ট 'F' (GPA 0.00) দেখাচ্ছে। কোডের লজিক ঠিক আছে, তাই ডাটাবেসে `students`, `mark`, এবং `subject` টেবিলের ডেটা কীভাবে সেভ হচ্ছে তা বিশ্লেষণ করে এই ফোল্ডারে রাখা হবে, যাতে মূল কারণটি (Root Cause) চিহ্নিত করা যায়।
